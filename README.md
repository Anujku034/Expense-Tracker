# 💰 Expense Tracker

A simple and user-friendly Expense Tracker built using HTML, CSS, and JavaScript.

## 🚀 Live Demo

[View Live Website](https://anujku034.github.io/Expense-Tracker/LoginPage/TrackerSystem.html)

## ✨ Features

- Add and manage expenses
- Track income and expenses
- Calculate balance
- User-friendly interface
- Responsive design
- Data handling using JavaScript

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

## 📌 Project Overview

This project is designed to help users track their income and expenses in a simple and organized way. It was built to strengthen my understanding of JavaScript, DOM manipulation, event handling, and Local Storage.

## 🎯 What I Learned

- DOM Manipulation
- JavaScript Event Handling
- Local Storage
- Form Handling
- JavaScript Logic
- Responsive Frontend Design
